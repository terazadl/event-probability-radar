# 中美日国债收益率对比与解读 2026-07-14

日期：2026-07-14
快照：2026 年 7 月中
标签：#宏观 #利率 #国债 #中美日 #CFA #投研系统

## 一句话

美国在"防过热"、日本在"脱通缩"、中国在"抗通缩"——三大经济体分处周期与政策周期的不同位置，10 年期国债收益率一个高位、一个上行、一个探底，且两边央行都在**反向干预**。

## 指标表（10 年期国债收益率）

| 国家 | 10Y 收益率 | 货币政策方向 | 周期位置 |
|---|---:|---|---|
| 美国 | ~4.56% | 或再加息 ↑（防通胀）| 防过热 / 晚周期 |
| 日本 | ~2.82%（30 年新高）| 加息中 ↑（脱通缩）| 再通胀 / 政策转向 |
| 中国 | ~1.73%（近历史低位）| 宽松 ↓（抗通缩）| 通缩风险 / 宽松 |

> 注：中国 10Y 已明显**低于**日本——几十年来"超低利率"是日本代名词，如今反转，市场讨论"中国日本化"。

## 六大看点

1. **罕见的"三向背离"**：三大经济体货币政策同时朝三个方向走。
2. **中国收益率低于日本**：历史性反转（见"中国日本化"讨论）。
3. **同样"收益率变动"含义相反**：日本升=好（脱通缩）；中国降=警报（通缩）；美国高=混合（韧性+通胀+财政期限溢价）。判断前先问：它在"脱离通缩"还是"陷入通缩"？
4. **收益率曲线作为先行指标**：美国 2s10s 2022–24 长期倒挂（预告放缓），现转正但仍平（~+36bp）——脱离衰退警报、非强劲扩张。
5. **跨境联动风险**：① 日元套息（美日利差收窄→carry unwind→全球波动）；② 中美利差深度倒挂（中国低约 280bp）→ 人民币贬值 + 资本外流。
6. **财政/债务暗线**：日本债务 ~250% GDP，收益率每升付息剧增；美国大赤字推高期限溢价；中国低收益率利于融资但反映私人需求弱。

## 日本上行：四条线叠加（不止"抗通缩"）

1. **真实通胀 + 正常化**：49 个月里 45 个月 CPI>2%，核心核心通胀 41/43 个月≥2%。BOJ 加息有底气。
2. **财政扩张 / 供给**（大头）：高市（Takaichi）拟暂停 8% 食品消费税两年（约 ¥5 万亿/年）、增支出、¥370 万亿投资路线图 → 更多国债发行 + 财政担忧 → 期限溢价 ↑。
3. **结构性：弱日元 + 贸易/竞争力**：贸易顺差已消失（能源进口、产能外移、竞争力下降）。
   - 关键区分：贸易顺差没了，但**经常账户仍顺差**——靠海外投资收益（primary income）。日本已从"**贸易立国**"变"**投资立国**"。贸易顺差减少 ≠ 外部融资断裂；它主要通过"弱日元→输入通胀"间接推高收益率。
4. **全球长端共振**：2026 年华盛顿—伦敦—东京债市集体承压。
   - 反方（Capital Economics）：别拿 Truss 类比，日本净债务/GDP 或降到 ~100%，"财政恐慌"部分被夸大，更像"新常态"。

## 中国低收益率：五种解读（超越"通缩"叙事）

1. **金融抑制 / 人为压低**：存款利率被管 30+ 年；PBOC 现在反而**托底**（6 月净买债从 ¥500 亿砍到 ¥100 亿），防跌太狠。
2. **资产荒**：房产退出储蓄工具、股市弱，储蓄涌入债市。是"缺资产"而非纯"缺信心"。
3. **债务管理**：压低收益率给政府/地方发债降成本（2026 年政府债务预计再增约 1 万亿美元）。
4. **反方：未必"日本化"**：政策空间还在、去杠杆更早期、资本管制锁资金、可主动再通胀。
5. **资产负债表衰退（辜朝明框架）**：私人部门忙还债不借钱，利率再低也不借→信贷需求塌陷→收益率被动下行（"推绳子"）。

## 总对比

- **日本**：多因素**推着**收益率往上（通胀+财政+结构+全球），BOJ 想让它别涨太快。
- **中国**：多因素**压着**收益率往下（通缩+金融抑制+资产荒+去杠杆），PBOC 想让它别跌太狠。
